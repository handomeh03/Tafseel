## 🛋️ Project Idea
A digital SaaS platform tailored for the furniture manufacturing and custom upholstery industry. The platform bridges the gap between furniture makers/workshops and customers, providing each maker with a digital storefront to showcase their designs and products (sofas, tables, bedrooms, decor). It enables users to browse products, filter selections, and seamlessly submit custom purchase orders with delivery locations and details.

---

## 💻 Tech Stack

- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS, TanStack React Query, React Hook Form, Zod
- **Backend:** NestJS, Node.js, TypeScript, Prisma ORM, PostgreSQL
